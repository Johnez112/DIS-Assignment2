# Painting company database

Assignment 2

- customers.db - customer info
- projects.db - painting jobs
- inventory.db - paint stock

In the app you can choose which database to open from the top menu. You can
view, add, edit and delete rows, and there is a search too.

Made with Python, Flask and SQLite.

## Running

    python -m pip install -r requirements.txt
    python app.py

Then go to http://127.0.0.1:5000

The databases already have some dummy data. If you want to reset the data,
run `python seed.py` or press the "Reset dummy data" button in the app.

Declaration of AI usage

I used Claude Opus 5.5 to generate sample data for databases. Also i used it to make my html look better and clear errors from code. I did code stack planning myself and idea came from my own painting company.
